One line, one joke about office life:

> Our standup is 15 minutes long. It has been running for 45 minutes, and nobody has stood up once.

The joke lands on a shared office ritual everyone recognises — the "15-minute" standup that never ends — and the twist arrives in the last few words: nobody has stood up once. `main.ts` writes the line to `/output/entry.txt` with a gate guard enforcing the 1–200 character single-line rule.
